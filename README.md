# NFSU2 Unlimiter
NFSU2 Unlimiter is a script mod which fixes some issues and makes some improvements for added cars and events.

### Features
- All the features of NFSU2 Unlimiter are listed in our [wiki](https://github.com/nlgxzef/NFSU2Unlimiter/wiki/Features). (Work in progress)

### AI Notice
- This mod partially utilizes GitHub Copilot and Claude.
- They are used mainly as advanced autocomplete and code-assistance tools rather than creating complete features.
- All AI generated content is reviewed, tested and approved by developers before actually getting implemented in the mod.

# Notes
- NFSU2 Unlimiter modifies game code and assets. If you compile from the source code, you will not be able to get the customized assets.
> Binarius script to install the mod will also install those assets. If you want to work with the source code, install the latest release as explained in the read me first and then copy over your (customized) build of Unlimiter.

# Download
You can [download Unlimiter](https://github.com/nlgxzef/NFSU2Unlimiter/releases) from Releases page (along with pre-releases), or from [NFSMods.xyz](https://www.nfsmods.xyz) (latest final release).
If you want to compile it yourself, you can download the source code from the green Clone or Download button up there.
